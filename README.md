# Wadee Kharbat

I’m a software engineering graduate in Riyadh with a focus on AI and experience in business analysis. I build tools that help people understand what happened in a system and trace the findings back to the evidence.

## Selected projects

- [HAR Inspector](https://github.com/wadeekharbat/har-inspector) — Inspect browser network recordings locally and find failed or slow requests.
- [Workflow Reconstruction](https://github.com/wadeekharbat/workflow-reconstruction) — Reconstruct how work moved through a process using CSV event logs, with links back to the source rows.
- [Python Wheel Coverage](https://github.com/wadeekharbat/python-wheel-coverage) — Check whether a staged Python release includes wheels for the Python versions and platforms it aims to support.
